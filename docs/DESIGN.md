# DESIGN.md

시각·청각 디자인. 에셋 선택 기준과 톤.

---

## 1. 톤

**"귀엽지만 긴장된다."**

숨바꼭질은 무서운 게임이 아니다. 친구들과 낄낄대며 하는 게임이다. 그런데 술래가 가까워지는 순간엔 심장이 뛰어야 한다.

- 기본 팔레트: 채도 낮은 파스텔 + 어두운 배경
- 캐릭터: 단순한 형태, 큰 실루엣 (작은 화면에서 구분돼야 함)
- 긴장은 **색이 아니라 어둠과 소리로** 만든다. 시야 밖은 거의 검게

---

## 2. 색

```css
--bg-void:      #0f1117;   /* 시야 밖 */
--bg-floor:     #1c2030;   /* 바닥 */
--wall:         #2c3247;
--light:        #ffe9b8;   /* 술래 손전등 */
--danger:       #e8576b;   /* 타이머 경고, 링 밖 */
--safe:         #5fd3a0;   /* 탈출구, 안전 */
--stealth:      #6aa9ff;   /* 살금살금 상태 */
--ghost:        #8b93ad;   /* 유령 */
```

플레이어 색 12개는 **명도까지 다르게** 뽑는다. 색맹 사용자가 명도로 구분할 수 있어야 한다.

## 3. 에셋 원칙

| 원칙 | 이유 |
|---|---|
| CC0만 사용 | H7. 법적 리스크 0 |
| 한 팩에서 최대한 가져온다 | 스타일 통일. 여러 팩을 섞으면 어수선해진다 |
| 16×16 또는 32×32 픽셀 그리드 | 아틀라스 패킹 효율, 확대 시 선명 |
| 출처를 반드시 기록 | `docs/generated/asset-manifest.md` |

### 기본 팩

**Kenney** 에셋을 주축으로 쓴다. 전부 CC0 1.0이고, 스타일이 통일돼 있고, 팩 간 호환이 좋다.

- 탑다운 캐릭터·타일 → Kenney *Top-down Shooter* (580개) / *1-Bit Pack* (1000+ 타일)
- 실내 오브젝트 → Kenney *Scribble Dungeons* (256+, 탑다운 실내)
- 모바일 조작 UI → Kenney *Onscreen Controls* (400개, 8스타일)
- 메뉴·버튼·패널 → Kenney *UI Pack*
- 효과음 → Kenney *Interface Sounds* (100개 OGG)

정확한 URL·라이선스 원문·사용 파일 목록은 `docs/generated/asset-manifest.md`.

> **주의**: Kenney 페이지 중 일부 캐릭터는 "Kenney Game Assets 2 전용"으로 표시된다(무료 팩에는 미포함). 매니페스트에 넣기 전에 **실제 zip을 받아 파일이 있는지 확인**한다. 미리보기 이미지만 보고 목록을 만들지 않는다.

### 우리가 직접 만들어야 하는 것

CC0 팩으로 안 되는 것들:

- **시야 원뿔 셰이더** — 코드
- **소음 방향 화살표** — SVG로 직접 (단순 도형)
- **빙의 오브젝트 하이라이트** — 셰이더 아웃라인
- **링 경계 (럼블)** — 셰이더

전부 도형/셰이더라 외부 에셋이 필요 없다.

## 4. 소리

소리가 이 게임의 절반이다 (PRODUCT_SENSE G1).

| 소리 | 역할 | 처리 |
|---|---|---|
| 발소리 | 긴장의 핵심 | 거리에 따라 볼륨, **방향에 따라 스테레오 팬** |
| 대시 | 큰 신호 | 저역 강조 |
| 빙의/해제 | 작은 신호 | 짧고 건조하게 |
| 탈출구 개방 | 지속 경보 | 루프, 점점 커짐 |
| 잡힘 | 결정적 순간 | 정적 0.2초 후 임팩트 |
| 유령 쿵 | 교란 | **진짜 발소리와 구분 안 되게** — 의도된 설계 |

WebAudio `PannerNode`로 2D 공간 오디오. 술래에게는 이게 주된 정보원이다.

**BGM 없음.** 정적이 긴장을 만든다. 로비에만 조용한 루프 하나.

## 5. 피드백 (게임필)

작은 것들이 체감을 만든다.

| 상황 | 피드백 |
|---|---|
| 이동 시작/정지 | 캐릭터 살짝 기울임 (8°) |
| 대시 | 잔상 3프레임 + 화면 살짝 줌아웃 |
| 잡힘 | 화면 흰색 플래시 1프레임 + 진동 + 정적 |
| 살금살금 진입 | 조이스틱 링 파랑, 발밑 소음 원 사라짐 |
| 소음 감지 (술래) | 화면 가장자리 화살표 페이드인 |
| 링 수축 임박 (럼블) | 화면 가장자리 붉은 비네트 맥동 |
| 타이머 30초 | 숫자 붉게 + 초당 펄스 |

`prefers-reduced-motion`이면 흔들림·줌·플래시를 전부 끈다. 정보는 색과 아이콘으로만 전달.

---

## 6. 폰트

- 한글: Pretendard 또는 Noto Sans KR — **상용 2350자 + 영숫자 서브셋**만 (WOFF2, ≤180KB)
- 숫자/타이머: `font-variant-numeric: tabular-nums` (자릿수 흔들림 방지)
- 게임 화면 안 텍스트는 최소 14px (모바일 가독성)

라이선스: Pretendard(OFL), Noto Sans KR(OFL) — 둘 다 재배포 가능. 매니페스트에 기록.

## 7. 검토 기준

디자인 PR은 다음을 만족해야 한다:

- [ ] 360px 폭(작은 폰)에서 UI가 겹치지 않는다
- [ ] 명도만으로 팀/상태가 구분된다 (흑백 스크린샷 테스트)
- [ ] 새 에셋이면 매니페스트에 출처·라이선스가 기록됐다
- [ ] 애니메이션이 `transform`/`opacity`만 쓴다
