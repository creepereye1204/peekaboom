## 조이스틱 (플로팅)

| 항목 | 값 |
|---|---|
| 활성 영역 | 화면 왼쪽 40% × 하단 70% (설정에서 좌우 반전 가능) |
| 중심 | **터치를 시작한 지점** (고정 아님) |
| 손잡이 지름 | 56 CSS px |
| 바깥 링 지름 | 128 CSS px |
| 최대 반경 | 64 CSS px |
| 데드존 | 반경의 12% (≈ 7.7px) |
| 살금살금 임계 | 반경의 50% 이하 |
| 시각 | Kenney *Onscreen Controls* — `flat_dark` 스타일, 투명도 65% |

터치를 떼면 손잡이가 사라진다(페이드 120ms). 다시 터치하면 그 자리에 다시 생긴다.

**살금살금 피드백**: 반경 50% 이하일 때 링이 파란색으로 바뀌고 캐릭터 발밑의 소음 원이 사라진다. 지금 조용한지 아닌지가 화면에서 보여야 한다.

## 액션 버튼

| 버튼 | 크기 | 위치 | 동작 |
|---|---|---|---|
| E (상호작용) | 72px | 오른쪽 아래, 가장자리에서 24px | 탭 = 빙의/해제, 길게 = 탈출구 개방 (원형 진행 표시) |
| ⚡ (대시) | 64px | E 왼쪽 아래 16px 간격 | 탭. 쿨다운 중엔 회색 + 원형 타이머 |
| 🔦 (스캔, 술래만) | 64px | E 위 16px 간격 | 술래일 때만 표시 |

- 최소 터치 타겟 48×48 보장 (시각 크기보다 히트박스가 8px 여유)
- 사용 불가 상태면 **투명도 30% + 비활성**, 숨기지 않는다 (있다는 걸 알아야 배운다)
- 누를 수 있게 되는 순간 **한 번 펄스** — 빙의 가능 오브젝트에 다가가면 E가 반짝인다

## 상단 HUD

| 요소 | 내용 |
|---|---|
| ⏱ 타이머 | `MM:SS`. 30초 남으면 빨강 + 초당 펄스 |
| 소음 화살표 | 화면 가장자리에 방향 표시. 강도에 따라 크기/투명도 (술래 전용) |
| 체력 (럼블) | 상단 중앙 바 |
| 링 표시 (럼블) | 미니맵 원. 다음 링 위치 예고 |
| ☰ 메뉴 | 나가기 / 설정 / 조이스틱 좌우 반전 / 소리 |

**미니맵은 숨바꼭질에서 술래에게도 안 준다.** 좌표 정보이기 때문이다(DD-002). 럼블에서만 링과 플레이어 점을 준다.

## 멀티터치 규칙

포인터 ID로 소유권을 추적한다.

```
touchstart → 좌표가 조이스틱 활성 영역이면: 조이스틱 소유
            액션 버튼 히트박스면: 그 버튼 소유
            둘 다 아니면: 무시 (조준용으로 쓰지 않음)
touchmove  → 소유한 포인터만 처리
touchend/cancel → 소유권 해제
```

손가락 3~4개가 동시에 닿아도 꼬이지 않아야 한다. 특히 **조이스틱을 움직이면서 대시를 누르는 것**은 매우 흔한 동작이므로 반드시 동작해야 한다.

## 성능 · 배터리

| 항목 | 정책 |
|---|---|
| 목표 프레임 | 60fps. 3초 연속 45fps 미만이면 **30fps 고정으로 전환** |
| 해상도 | `devicePixelRatio` 사용하되 상한 2.0. 그 이상은 발열 대비 이득이 없다 |
| 저전력 모드 감지 | 감지 API가 없다. 대신 위 프레임 기반 자동 강등으로 대응 |
| 화면 꺼짐 방지 | `navigator.wakeLock` — 실패해도 조용히 넘어감 |
| 백그라운드 | 입력 전송 중단, 렌더 중단. 스냅샷 수신은 유지 |

## 접근성

- 색맹 대응: 팀/상태를 색으로만 구분하지 않는다. 아이콘 모양도 다르게
- 소음 화살표에 색 + 크기 + 채움 패턴 3중 인코딩
- 버튼 라벨은 아이콘 + (설정에서 켜면) 텍스트
- 진동 피드백: 잡힘/태그/링 진입 시 `navigator.vibrate()`. 설정에서 끌 수 있음

## 검증 방법

플레이스홀더 스크린샷으로 통과시키지 않는다. 실기에서 확인한다:

- [ ] 중급 안드로이드 1대 (예: 갤럭시 A 시리즈)
- [ ] iPhone 1대 (Safari, 노치 있는 기종)
- [ ] 세로/가로 회전 중 게임 유지
- [ ] 조이스틱 + 대시 동시 입력
- [ ] 30분 연속 플레이 시 발열/배터리 체감

기기가 없으면 "미확인"이라고 적는다 (AGENTS.md §5).
