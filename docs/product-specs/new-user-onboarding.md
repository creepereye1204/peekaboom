# 제품 스펙 · 첫 사용자 온보딩

친구가 보낸 링크로 처음 들어온 사람. 게임 이름도 모르고, 튜토리얼을 읽을 생각도 없다.

---

## 원칙

**튜토리얼 화면을 만들지 않는다.** 아무도 안 읽는다. 대신 게임 안에서 필요한 순간에 한 줄씩 알려준다.

---

## 첫 라운드에만 나오는 힌트

`localStorage.peekaboom.seen_hints`에 기록. 한 번 본 힌트는 다시 안 나온다.

| 시점 | 힌트 | 위치 |
|---|---|---|
| 숨는 시간 시작 | "20초 안에 숨으세요" | 화면 중앙 상단, 2초 |
| 처음 이동 | (없음 — 조작은 알아서 안다) | |
| 빙의 가능 오브젝트 근처 | "E로 숨을 수 있어요" / 모바일: 버튼이 반짝임 | 오브젝트 위 |
| 술래로 처음 배정 | "손전등 안이 보이는 범위예요" | 화면 중앙, 3초 |
| 처음 소음 감지 | "소리가 난 방향이에요" (화살표 강조) | 화살표 옆 |
| 처음 잡힘 | "이제 유령이에요. 소리를 내서 도울 수 있어요" | 중앙, 3초 |
| 탈출구 처음 발견 | "3초 누르면 열려요. 시끄러워요" | 탈출구 위 |

전부 **한 문장**, 전부 **자동으로 사라짐**, 전부 **닫기 버튼 없음**. 읽든 말든 게임은 진행된다.

## 모바일 첫 진입

세로로 들어왔으면 **한 번만**:

> 가로로 돌리면 더 잘 보여요

"다시 보지 않기" 없음 — 어차피 한 번만 나온다. 세로로 계속 해도 된다 (DD-005).

## 이름

자동 생성: `<색깔><동물>` — 초록너구리, 붉은수달, 파란고양이…

- 색 12개 × 동물 20개 = 240 조합. 같은 방 중복은 뒤에 숫자
- 이미 채워진 상태로 뜨고, 그냥 시작 버튼 누르면 된다
- 바꾸면 `localStorage`에 저장 → 다음에 그 이름으로

## 첫 라운드 배려

첫 접속자에게 **첫 라운드는 술래를 안 시킨다** (다른 후보가 있으면).

> 왜: 규칙을 모르는 채로 술래가 되면 다른 사람들의 라운드까지 재미없어진다. 한 판 숨어보면서 배우게 한다.

- 연습 모드 / AI 봇 — v1 범위 밖
- 설정 마법사 — 설정할 게 없는 게 맞다
