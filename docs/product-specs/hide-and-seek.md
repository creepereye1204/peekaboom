# 제품 스펙 · 숨바꼭질 (Hide & Seek)

기본 모드. 처음 들어온 사람이 설명 없이 이해할 수 있어야 한다.

---

## 한 줄

**술래 1명이 숨은 사람들을 찾는다. 숨은 사람은 안 잡히고 버티거나, 탈출구를 열어 나간다.**

---

## 라운드 흐름

```
로비  →  숨는 시간 20초  →  추격 180초  →  결과 10초  →  로비
        (술래 화면 암전)    (술래 이동 시작)
```

| 단계 | 길이 | 내용 |
|---|---|---|
| 숨는 시간 | 20초 | 술래는 화면이 어두워지고 이동 불가. 숨는 쪽은 자유 이동 |
| 추격 | 180초 | 술래 이동 개시. 타이머 표시 |
| 결과 | 10초 | 생존자 / 잡힌 사람 표시, 다음 술래 예고 |

### 승리 조건

- **숨은 쪽 승리**: 180초 동안 1명 이상 생존, 또는 탈출구로 1명 이상 탈출
- **술래 승리**: 180초 안에 전원 검거

### 다음 술래

**마지막에 잡힌 사람**이 다음 술래. (전원 잡히면 가장 먼저 잡힌 사람 — 빨리 잡히면 손해가 되도록)
탈출한 사람은 술래 후보에서 제외된다.

---

## 플레이어 능력

### 숨는 쪽

| 행동 | 조작 | 규칙 |
|---|---|---|
| 이동 | 조이스틱 / WASD | 기본 속도 4.0 타일/초 |
| 살금살금 | 조이스틱 반 이하로 밀기 | 속도 1.8, **발소리 안 남** |
| 사물 빙의 | E (지정 오브젝트 위에서) | 상자·화분·자판기로 변한다. 이동 불가. 해제 0.5초 |
| 대시 | Shift / 버튼 | 1.2초간 속도 7.0. 쿨다운 8초. **큰 소음 발생** |
| 탈출구 개방 | E 길게 (3초) | 맵에 3곳. 1곳만 열면 됨. 개방 중 소음 계속 |

### 술래

| 행동 | 조작 | 규칙 |
|---|---|---|
| 이동 | 조이스틱 / WASD | 기본 속도 4.4 타일/초 (약간 빠름) |
| 잡기 | 자동 | 반경 1.2타일 안에 들어오면 즉시 |
| 손전등 | 마우스 / 조이스틱 방향 | 전방 60°, 거리 9타일. 이 안이 **시야** |
| 소음 감지 | 자동 | 반경 12타일 내 소음의 **방향만** 화면 가장자리에 표시 |
| 스캔 | 버튼 | 3초 충전 후 반경 6타일 내 "사물 빙의" 오브젝트를 0.6초간 반짝임. 쿨다운 25초 |

### 잡힌 뒤

관전이 아니라 **유령**이 된다.

- 맵 전체를 자유롭게 떠다닌다 (숨은 사람에겐 안 보임)
- 3초 쿨다운으로 **한 번 "쿵" 소리**를 낼 수 있다 — 술래를 속이거나 동료에게 경고
- 유령끼리는 채팅 가능

> 왜: 잡히고 나서 할 게 없으면 사람들이 탭을 닫는다. 유령에게 작은 영향력을 주면 끝까지 남는다. 단, 영향력이 크면 밸런스가 깨지므로 "소리 하나"로 제한.

## 소음 시스템

숨바꼭질의 실제 긴장감은 시각이 아니라 **소리**에서 나온다.

| 행동 | 소음 반경 | 술래에게 표시되는 것 |
|---|---|---|
| 걷기 | 7타일 | 방향 화살표 (약) |
| 살금살금 | 0 | 없음 |
| 대시 | 14타일 | 방향 화살표 (강) + 화면 살짝 흔들림 |
| 빙의/해제 | 4타일 | 방향 화살표 (약) |
| 탈출구 개방 | 16타일, 지속 | 방향 화살표 (강, 깜빡임) |
| 유령 쿵 | 10타일 | 방향 화살표 (중) — 술래는 진짜인지 구분 못 함 |

**방향만 준다. 거리는 안 준다.** DD-002의 좌표 비공개 원칙과 같은 이유이자, 게임적으로도 "어디쯤인지 애매한" 상태가 재밌다.

## 맵

- 64×40 타일, 실내 (사무실 / 학교 / 마트 중 하나 — 시작은 1개만). 규격과 설계 규칙은 [DD-009](../design-docs/map-design.md)
- 방 8~12개, 문·통로로 연결. **막다른 골목은 2개 이하** (도망 경로가 항상 있어야 함)
- 빙의 가능 오브젝트 40~60개, 방마다 성격이 다르게 (사무실=서류함, 마트=진열대)
- 탈출구 3곳, 서로 최대한 멀게 배치

## 밸런스 초기값

아래 숫자는 **추측이다. 플레이테스트 전까지 신뢰하지 않는다.**

| 인원 | 술래 | 숨는 쪽 | 추격 시간 |
|---|---|---|---|
| 3~4 | 1 | 2~3 | 150초 |
| 5~6 | 1 | 4~5 | 180초 |
| 7~8 | 2 | 5~6 | 180초 |

7명 이상에서 술래 2명인 이유: 1명으로는 맵이 너무 넓어 지루해진다.

- 음성 채팅 — WebRTC로 가능하지만 범위 밖. 사람들은 어차피 디스코드를 켠다
- 맵 에디터 — v1 범위 밖
