## 스펙을 쓸 때 지키는 것

1. **사용자가 보는 것부터 쓴다.** 구현 방법은 design-doc에
2. **"만들지 않는 것" 섹션을 반드시 넣는다.** 범위를 자르는 게 스펙의 절반이다
3. **숫자는 출처를 밝힌다.** 추측이면 "미검증 추측치"라고 쓴다. 나중 사람이 그 숫자를 믿고 튜닝하면 안 된다
4. **UI 문구는 실제 문구를 쓴다.** "적절한 에러 메시지 표시" 같은 건 스펙이 아니다

## 현재 범위 밖 (v1에서 안 함)

- 음성 채팅
- 맵 에디터
- 팀전
- 전적/랭킹 (서버가 없어 저장 불가)
- 커스터마이징
- 관전자 모드 (유령은 있지만 순수 관전은 없음)
