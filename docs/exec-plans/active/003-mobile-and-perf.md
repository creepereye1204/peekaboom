# 003 · 모바일 완성도와 성능 실측

- 상태: **대기** (002 완료 후)
- 마일스톤: M3
- 목표: **중급 안드로이드와 아이폰에서 30분 연속 플레이가 견딜 만하다**

---

## 왜 이 시점인가

모바일은 1차 타겟이다 (CB-4). 그런데 재미가 검증되기 전에 최적화하면, 나중에 게임플레이가 바뀌면서 최적화가 무의미해진다.

002에서 "재밌다"가 확인된 직후가 최적 타이밍이다.

---

## 이 계획의 성격: 측정이 산출물

지금까지 문서의 모든 성능 숫자는 **계산값이거나 목표값이다** (TD-006).

| 문서 | 숫자 | 상태 |
|---|---|---|
| DD-004 | 프레임 16ms, 드로우콜 ≤3, 인스턴스 ≤500 | 목표 |
| generated/net-protocol.md | 업로드 7.9 KB/s, 다운로드 8.4 KB/s | 계산 |
| FRONTEND.md | 아틀라스 400KB, 폰트 180KB, WASM 1.5MB | 예산 |
| DD-002 | 레이캐스트 64회/틱이 "문제없는 수준" | 추측 |

**이 계획이 끝나면 전부 실측값으로 바뀌어야 한다.** 바뀌지 않으면 계획을 완료 처리하지 않는다.

## 체크리스트

### 1. 터치 조작 완성 (DD-005, mobile-controls.md)

- [ ] 플로팅 조이스틱 — 터치 시작 지점이 중심
  - [ ] 데드존 12%, 최대 반경 64 CSS px
  - [ ] **데드존 경계에서 값이 튀지 않게 재매핑** ([deadzone,1] → [0,1])
  - [ ] 살금살금(반경 50% 이하) 시 링 색 변경 + 발밑 소음 원 사라짐
- [ ] 액션 버튼 E / 대시 / 스캔(술래)
  - [ ] 히트박스가 시각 크기보다 8px 여유 (최소 48×48)
  - [ ] 사용 불가 시 투명도 30%, **숨기지 않는다**
  - [ ] 가능해지는 순간 한 번 펄스
- [ ] 포인터 ID 소유권 추적
  - [ ] **조이스틱 조작 중 대시 누르기가 반드시 동작해야 한다.** 가장 흔한 동작
- [ ] Kenney Onscreen Controls 에셋 적용 (매니페스트 갱신)

### 2. 모바일 환경 처리

- [ ] `touch-action: none` + `preventDefault` (스크롤/줌이 조작을 먹지 않게)
- [ ] `viewport-fit=cover` + `env(safe-area-inset-*)` (노치/홈바)
- [ ] 세로↔가로 회전 시 **게임이 멈추지 않는다**
- [ ] 세로 모드 첫 진입 1회 안내 ("가로로 돌리면 더 잘 보여요"). 강제하지 않음
- [ ] `navigator.wakeLock` — 실패해도 조용히 넘어감
- [ ] 첫 터치에서 `AudioContext.resume()`
- [ ] `visibilitychange` → 입력 중단, 스냅샷 수신 유지, 복귀 시 강제 동기화
- [ ] 창 `blur` → 모든 키/포인터 해제 (안 하면 alt-tab 후 계속 달린다)

### 3. 성능

- [ ] DPR 상한 2.0
- [ ] 3초 연속 45fps 미만 → **30fps 고정으로 자동 강등**
- [ ] 프레임당 힙 할당 0 (인스턴스 버퍼 재사용)
- [ ] DOM 갱신은 값 변경 시에만
- [ ] 애니메이션은 `transform`/`opacity`만
- [ ] `prefers-reduced-motion` → 흔들림/줌/플래시 끔

### 4. 번들 예산 (H5)

- [ ] `wasm-opt -Oz`
- [ ] 한글 폰트 서브셋 (`pyftsubset`, 상용 2350자 + 영숫자) — 실측 크기 기록
- [ ] 아틀라스 팔레트 최적화
- [ ] `tools/check_size.sh` CI 연동 — 1.5MB 초과 시 빌드 실패

### 5. 접근성

- [ ] 흑백 스크린샷에서 팀/상태 구분 가능 (색 + 아이콘 모양 이중 인코딩)
- [ ] 소음 화살표: 색 + 크기 + 채움 패턴 3중
- [ ] 진동 피드백 (`navigator.vibrate`), 설정에서 끌 수 있음
- [ ] 게임 화면 텍스트 최소 14px

## 완료 조건

1. 위 매트릭스가 채워졌다 (미확인은 "미확인"으로 명시)
2. 번들 예산 통과, CI에 연동됐다
3. TD-006(성능 수치 미측정)이 해소됐다 — 관련 문서의 숫자가 실측값으로 갱신됐다
4. 30분 연속 플레이에서 조작 불능 수준의 발열/끊김이 없다
